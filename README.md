# Firma Grupocine

Archivos que usan las firmas de mail del equipo. Se publican con GitHub Pages.

## Cambiar las películas en cartel (cada semana)

1. Abrí `semana.json` y tocá el lápiz (Editar).
2. Cambiá los títulos y, si querés, el enlace.
3. Tocá **Commit changes**.

En uno o dos minutos se regenera `en-cartel.gif` y todas las firmas muestran las películas nuevas.
Gmail guarda una copia temporal de las imágenes, así que puede tardar unas horas en verse en todos los correos.

## Direcciones fijas (las que van en la firma)

- Logo: `https://<usuario>.github.io/firma/logo-grupocine.png`
- Línea animada: `https://<usuario>.github.io/firma/en-cartel.gif`
- Enlace de la semana: `https://<usuario>.github.io/firma/estreno/`

## Cambiar el logo

Reemplazá `logo-grupocine.png` por una versión de buena calidad (PNG, idealmente con fondo transparente) con el mismo nombre.
